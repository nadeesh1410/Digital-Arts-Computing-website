# Hidden Veins — DAC 2026

**A single-page digital exhibition for Goldsmiths Digital Arts Computing**

## How to Add Your Work

Anyone can add their projects!

- Update the [Google Sheet](LINK_TO_EDITABLE_SHEET) as instructed by your coordinator.  
  (If your project uses a local CSV, edit `/data/projects.csv` instead and commit the changes.)
- No coding or Git required if using the Google Sheet.
- Your work will appear automatically—no code or website editing needed!

## How This Site Works

- All code and design are in `public/index.html`.
- Styles and scripts are embedded for simplicity.
- Gallery data comes directly from a published Google Sheet (CSV export).
- To change the sheet, just edit `CSV_URL` in the script block.
- Read the top of the script in `index.html` for all setup instructions!

## Hosting

For GitHub Pages, Netlify, or simple web hosts:  
Just serve the `/public` folder. That’s it!
